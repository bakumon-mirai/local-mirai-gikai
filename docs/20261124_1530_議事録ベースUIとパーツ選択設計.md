# 議事録ベース UI とパーツ選択 設計書

作成日: 2026-11-24

## 1. 背景と目的

地方議会の公開状況は自治体ごとに大きく異なる。議案本文が未公開（Tier 1）の自治体や、首長記者会見・委員会議事録の有無が自治体ごとに異なるケースでも、**利用者が調査結果を見ながら「この自治体で載せるパーツ」を選んで立ち上げられる**ようにする。

本設計書は、PR #178（議事録ベースのアーカイブ用 DB テーブルとサンプルデータの追加）に続く **2段階目（閲覧ページ・トップページパターン切り替え・パーツ選択）** の設計を定義する。

### 設計の原則

1. **調査レポートの機能表と `siteConfig` のパーツを 1 対 1 に対応させる**
   - 初心者でも調査レポートの `◯ / △ / ✗` を見ながら「どのパーツをオンにするか」を選べるようにする。
2. **「議案中心」と「議事録・活動中心」の 2 つのトップページ型を選べるようにする**
   - `siteConfig.homeLayout` で `"bills"`（既定・後方互換）と `"archive"`（議事録・活動中心）を切り替える。
3. **パーツがオフ／データ未登録でも画面が破綻しない**
   - 無効なパーツのルートは `notFound()` を返し、ナビ・検索・トップから自動的に消える。
   - 議事録ベース（`"archive"`）の閉会中ヒーローは、首長記者会見が無い自治体でも自動で委員会・一般質問へフォールバックする。
4. **自治体固有の語彙・配色・制度をハードコードしない**
   - 首長の呼称（知事・市長・区長・町長・村長）、行政呼称（県政・市政・区政・町政・村政）、定例会開催月（`[3, 6, 9, 12]` / `[2, 6, 9, 12]` 等）をすべて `siteConfig` から参照する。
   - 予算概要・事務事業評価など自治体ごとのデータ構造差が大きい独自機能は、PR #178 の方針どおりテンプレート本体には含めない。

## 2. `siteConfig` の設計

`web/src/config/site.config.ts` に以下の設定を追加する。

```ts
export const siteConfig = {
  // 既存項目（siteName, cityName, councilName, residentTerm 等）
  ...

  /** トップページの構成（"bills": 議案中心 / "archive": 議事録・活動中心） */
  homeLayout: "bills" as "bills" | "archive",

  /** 首長の役職名（知事・市長・区長・町長・村長） */
  executiveTitle: "市長",
  /** 首長の氏名（任意。空文字列なら executiveTitle のみを表示） */
  executiveName: "",
  /** 行政の呼称（県政・市政・区政・町政・村政）。テーマ・分類ラベルに使用 */
  governmentTerm: "市政",
  /** 定例会の通常開催月（例: 市区町村は [3, 6, 9, 12]、都道府県は [2, 6, 9, 12]） */
  regularSessionMonths: [3, 6, 9, 12] as readonly number[],

  features: {
    /** 議案一覧・議案詳細 */
    bills: true,
    /** 会派別賛否（会派がない・可否のみの議会では false） */
    showFactionStances: true,
    /** 一般質問・代表質問アーカイブ */
    generalQuestions: true,
    /** 委員会議事録アーカイブ */
    committeeMinutes: true,
    /** 首長記者会見アーカイブ */
    pressConferences: true,
    /** 横断検索・テーマから探す */
    search: true,
    /** AIチャット機能 */
    aiChat: true,
    /** AIインタビュー機能 */
    aiInterview: false,
    /** チームみらいセクションの表示 */
    showTeamMiraiSection: false as boolean,
  },
} as const;
```

### 調査レポートとパーツ設定の対応

| 調査レポートの判定 | おすすめ `homeLayout` | `features` の目安 |
|---|---|---|
| Tier 2（議案本文あり） | `"bills"`（議案中心） | `bills: true` ＋ 取れるアーカイブパーツを `true` |
| Tier 1（議案本文なし）＋アーカイブ強/中 | `"archive"`（議事録・活動中心） | `bills: true`（議案一覧のみ利用可）＋ `generalQuestions` / `committeeMinutes` / `pressConferences` のうち取れるものを `true` |
| 会派別賛否なし（可否のみ・票数のみ・会派なし） | 上記と同じ | `showFactionStances: false` |
| 首長記者会見なし | 上記と同じ | `pressConferences: false` |
| 委員会議事録なし／匿名要約のみ | 上記と同じ | `committeeMinutes: false` |

## 3. ルート設計と PR #178 スキーマとの整合

すべてのルートを `web/src/lib/routes.ts` に登録し、`routes.test.ts` で `app/` と 1 対 1 対応を保証する。

| ルート | 対応パーツ | 備考 |
|---|---|---|
| `/sessions` | `bills` または `generalQuestions` | 過去の定例会一覧 |
| `/sessions/[slug]/bills` | `bills` | 既存ルート（`[slug]` を維持） |
| `/sessions/[slug]/questions` | `generalQuestions` | 会期別の一般質問・代表質問一覧 |
| `/questions` | `generalQuestions` | 質問が公開されている最新会期へリダイレクト |
| `/questions/[id]` | `generalQuestions` | 一般質問・代表質問の詳細（論点要約・チャット風・原文切替） |
| `/committees` | `committeeMinutes` | 委員会アーカイブ一覧 |
| `/committees/[slug]` | `committeeMinutes` | 委員会ごとの会議一覧 |
| `/committees/[slug]/[meetingId]` | `committeeMinutes` | 会議詳細（議題ごとの要約・発言範囲）。PR #178 に合わせ `meetingId`（UUID）を使用 |
| `/committees/[slug]/[meetingId]/transcript` | `committeeMinutes` | 会議録の全文閲覧（チャット風表示） |
| `/press-conferences` | `pressConferences` | 首長記者会見一覧 |
| `/press-conferences/[slug]` | `pressConferences` | 首長記者会見詳細（発表事項・配付資料・質疑応答）。発言者区分は `'executive' \| 'reporter' \| 'secretariat'` |
| `/search` | `search` | 横断検索（有効なパーツ［議案・一般質問・委員会］のみ検索・タブ表示） |

## 4. トップページ構成（PR 2 で実装）

### 4.1 `homeLayout: "bills"`（議案中心・既定）

既存の議案ベース構成（ヒーロー・本日の定例会・注目の議案・タグ別議案一覧・前回の定例会）を維持する。

### 4.2 `homeLayout: "archive"`（議事録・活動中心）

更新頻度の高い順に並べる構成を基本とし、有効かつデータがあるパーツのみ表示する。

1. **ヒーロー（`TopHero`）**
   - **会期中**: `InSessionHero`（会期の進み具合・`schedule_milestones` による会期の流れ・有効パーツの件数タイル）。`pressConferences` が有効かつデータがあれば直下に 1 行の会見帯を表示。
   - **閉会中（主役フォールバック）**: 右側ハイライトカードを次の優先順で自動選定する。
     1. `pressConferences` 有効＆最新会見あり → 首長記者会見カード
     2. `committeeMinutes` 有効＆最新会議あり → 委員会ハイライトカード
     3. `generalQuestions` 有効＆最新質問あり → 一般質問ハイライトカード
     4. いずれも未登録 → 1 カラムの簡潔なヒーロー表示
2. **定例会の帯（`SessionBand`）**: `regularSessionMonths` に基づく 4 枠。強調枠は常に 1 つ。
3. **委員会の最新の話し合い（`CommitteeSection`）**: `committeeMinutes` 有効かつ 1 件以上のとき表示。
4. **代表質問・一般質問から（`QuestionsSection`）**: `generalQuestions` 有効かつ 1 件以上のとき表示。
5. **気になるテーマから（`ThemeSection`）**: `search` 有効時、8 テーマタイルを表示（8 番目は `{governmentTerm}・お金` に動的対応）。
6. **議案サマリカード（`BottomCards`）**: `bills` 有効かつ議案があるとき表示。
7. **過去の定例会 / 首長記者会見アーカイブ / About / 免責事項**

### 4.3 カラートークン（PR 2）

福岡県版の `pref-*` トークンは汎用名 **`archive-*`** として `web/src/app/globals.css` に定義し、既定値はテンプレートのプレースホルダー配色（スレートブルー系 `--primary: #4f6d8c` に調和し、WCAG AA 4.5:1 以上を満たす値）とする。
